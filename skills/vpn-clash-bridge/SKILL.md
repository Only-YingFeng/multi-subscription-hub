# 桌面 VPN 到 Clash 的固定节点适配

将用户合法取得的节点接入 Clash 或多订阅浏览器后台，保留每条线路的身份、认证及独立选择。Skill 是供 Codex 复用的维护方法，不是 EXE 内置功能，不保证任意 VPN 都能提取。

## 先确定可行路径

用户询问可行性时只做只读检查；明确要求实施时再生成配置或改代码。只检查用户指定的客户端、配置路径与关联本地接口，不扫描整盘、其他账号或无关浏览器数据。

- **完整导出且标准协议兼容：** 核验服务器、端口、协议、TLS/传输参数及现有认证是否完整，再用目标核心验证；可直接转换为真实节点。
- **需要专用核心：** 确认已有、可信且允许使用的核心支持指定节点及独立入口，才实现桥接；保留核心运行依赖，不能承诺卸载全部文件后可用。
- **只有一个本地代理：** 最多作为一个跟随原客户端选择的入口。多个别名或重复 SOCKS 地址不能构成多条独立线路。
- **仅有名称或不完整参数：** 报告缺项和“尚不能生成可连接节点”。先寻找官方导出或用户已有配置，不以猜测补全。

不猜测密码、枚举凭据、伪造授权、破解会员或绕过访问控制。收费节点需用户有服务商授予的相应权限；本工具无法独立证明会员有效，缓存配置和连通结果也不构成授权证明。

## 飞鸟适配中可复用的证据与约束

需要实现专用核心生命周期时阅读本仓库 [feiniao_bridge.py](../../original-source/feiniao_bridge.py)及其[隔离测试](../../original-source/tests/test_feiniao_bridge.py)；这些文件不是任意客户端节点提取器。接入现有多订阅应用时，检查 [backend.py](../../backend.py) 的 `_bridge_mapping`、`discover`、核心准备与桥接启动路径。

当前飞鸟实现验证固定 108 节点及端口 40000–40107，识别 `codex-feiniao-bridge` manifest；这些是已有适配的具体约束，不能套用为新客户端的数量、端口或类型。新客户端需要自己的适配标识、数据校验与端口登记；不要通过改名称或伪造飞鸟 manifest 声称已受支持。

可复用的结构是：可信兼容核心 + 私有真实节点配置 + 稳定端口映射 + 启停身份记录 + 供 Clash 导入的本地 SOCKS 配置。公开仓库不包含用户凭据或专用核心，缺少这些依赖时不能仅靠源码完成连接。

## 实施与验收

1. 记录当前主 Clash 的模式、配置、默认节点及系统代理/TUN/DNS状态，只保留脱敏摘要。将真实配置及既有扩展先备份到用户私有目录；不要打印订阅 URL、UUID、密码、控制密钥或完整配置。
2. 从用户已有合法导出、配置或获授权的本地接口读取节点。HTTP 200 或成功下载不足以证明有可用节点；核对实际内容及协议参数。订阅更新继续使用服务商支持的入口，不制作能够绕过授权的新远端“订阅”。
3. 为每个真实节点维护稳定身份与回环端口。顺序变化不得改变旧端口对应的线路；凭据轮换与改名需要按身份核验。身份无法确认时分配新端口，旧入口停用且保留登记，不交给另一条线路。
4. 每个入口只监听 `127.0.0.1` 并固定到一个节点；禁止测速选优、负载均衡、失败后换线或回落 DIRECT。私有配置访问权限限制到当前用户与必要系统身份；协议认证字段沿用原配置。
5. 生成候选后用实际目标核心校验，检查端口冲突及核心版本。保留主 Clash 原分流：直连和拦截动作保持，代理动作走该浏览器入口绑定节点，兜底也按已有明确规则处理。真实规则冲突只询问必要项。
6. 新建的桥接核心在 Windows 隐藏启动，记录 PID、创建时间、完整程序/配置身份及哈希。停止前重新核验所有权；借用既有核心时不停止它。不因 PID 相同就终止进程。
7. 可能中断现有网络的退出、重载、核心停止或切换动作先说明影响并取得明确确认；Skill 本身不提供授权。独立入口可以不改主 Clash，但仍须核对端口和原状态。
8. 执行低流量连通性测试和核心日志/路由核验，确认命中固定节点。配置校验、监听存在、HTTPS 成功、两入口同时独立选线、主 Clash 保持原状态分别验收。需要证明脱离官方 GUI 时，在获授权后退出 GUI 再测；保留兼容核心的依赖说明。
9. 仅生成本地 SOCKS5 情景模式组成的 ZeroOmega BAK，不新增 Auto Switch/PAC/GFWList。浏览器导入由用户手动完成，不写登录数据库或运行中的扩展存储。

完成后报告直接转换/专用核心桥接/单入口的实际类型、节点和端口数量、文件位置、运行依赖、测试范围及未测项，并提供相应启动、停止与回滚方法。回滚仅处理本工具管理的文件和进程；未获授权不删除原客户端或既有私有目录。

用户侧安装和导入步骤见 [Clash Verge Rev + ZeroOmega 教程](../../docs/clash-zeroomega-guide.md)。对外发布 Skill 或代码时另按用户明确授权核验文件范围与第三方许可；不得附带真实账号、私有配置或未经许可的核心文件。
