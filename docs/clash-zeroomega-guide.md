# Clash Verge Rev + ZeroOmega 使用教程

本教程说明如何用自己的有效订阅，让浏览器在右上角手动选择具体节点。原版与多订阅新版按需求选一个使用，无需同时启动。

## 先安装什么

1. 从 [Clash Verge Rev 官方 Release](https://github.com/clash-verge-rev/clash-verge-rev/releases)安装 Windows 客户端，导入自己的有效订阅，更新后确认可以看到节点。读取或缓存节点不代表套餐有效，使用权限仍由服务商决定。
2. 在 Chrome 打开 [ZeroOmega 官方商店页面](https://chromewebstore.google.com/detail/proxy-switchyomega-3-zero/pfnededegaaopdmhkdmcofjmoldfiped)，安装 **Proxy SwitchyOmega 3 (ZeroOmega)**。其[官方项目](https://github.com/zero-peak/ZeroOmega)提供同一安装链接；安装后从 Chrome 的扩展菜单将它固定到工具栏。
3. 在 [本项目 Release](https://github.com/Only-YingFeng/multi-subscription-hub/releases/latest)下载对应 EXE，放在自己的可写文件夹中运行。

Clash Verge Rev、ZeroOmega 和本项目分别由各自维护者提供。本项目不会提供机场会员、付费节点权限或破解功能。

## 用当前订阅：Clash 节点备份助手

1. 在 Clash Verge Rev 中更新并选中需要的订阅，保持**规则模式**，让主核心运行。
2. 打开 `ClashZeroOmega.exe`，点击 **探测环境**。检查节点列表及本次连通性结果；失败节点也会保留。
3. 选择输出目录，点击 **生成备份**。软件生成 `ZeroOmega-全节点-手动选择-Mihomo分流.bak` 和端口映射表。
4. 若显示 **待写回**，点击紫色 **写回 Clash 扩展配置**，阅读连接中断提示后确认。它会先私有备份、校验，再合并当前订阅持久扩展并热重载；成功后按钮变为绿色。已显示 **已写回并生效** 时无需重复操作。
5. 按下文步骤在 ZeroOmega 恢复这份 BAK，再从工具栏选择具体节点。

代理入口由主 Clash 提供，主 Clash 必须继续运行。电脑默认节点与这些固定入口分别选择，但切换到另一个订阅可能使旧入口失效；需要跨订阅同时使用时选择新版。

## 多个订阅同时用：多订阅后台助手

1. 在 Clash Verge Rev 中导入并更新自己的多个订阅，让软件读到完整本地配置；主 Clash 保持规则模式。
2. 打开 `MultiSubscriptionHub.exe`，点击 **刷新**，勾选要供浏览器使用的订阅。
3. 点击紫色 **启动浏览器后台**。启动成功后显示绿色 **已运行**；已有后台时更改勾选，点击 **应用订阅选择**。
4. 点击 **检测节点**查看本次结果，然后点击 **生成合并 BAK**。检测是推荐步骤，后台已校验健康时也允许直接生成。
5. 将 `ZeroOmega-多订阅-手动选择-独立分流.bak` 恢复到 ZeroOmega，选择具体节点。

**新版不需要写回主 Clash。** 浏览器连接自己的独立后台，电脑主 Clash 可以继续使用另一个订阅。后台必须持续运行，可以隐藏到托盘；点击 **停止后台** 后，对应入口无法连接。

普通 Clash 订阅无需飞鸟桥接。飞鸟兼容来源需要用户自己的完整桥接目录和兼容核心，公开 EXE 不包含它们，也不会自动读取任意 VPN EXE。

## 在 ZeroOmega 导入并选线

1. 打开 ZeroOmega 的 **选项**，找到 **导入/导出**。
2. 先 **导出备份文件**，保存原有选项。恢复备份会改变插件选项，需要保留原有模式时先核对自己的备份；不要直接导入别人的本机映射。
3. 点击 **从备份文件恢复**，选择本软件在自己电脑上生成的 `.bak`，按插件提示完成恢复。
4. 点击浏览器右上角 ZeroOmega 图标，选择具体节点名称，例如自己的“美国中转815”。该模式只保存本地 SOCKS5 地址与固定端口。
5. 不同浏览器或独立浏览器配置文件分别恢复并选择，可以同时走不同节点。

本工具生成的模式不需要再添加 Auto Switch、PAC 或 GFWList。流量进入本地核心后按规则分流：直连规则直连、拦截规则保持拦截、代理规则及未命中请求走所选入口绑定的节点。选择节点不会把所有网站强制代理，失效时也不会自动换线。

## 菜单里的三种选择

| ZeroOmega 选择 | 请求如何处理 |
| --- | --- |
| 具体节点情景模式 | 使用生成的固定本地入口，分流和代理连接由该入口所属核心执行 |
| 系统代理 | 跟随 Windows 当前系统代理；如果系统代理指向 Clash，就跟随主 Clash 的规则与节点选择 |
| 直接连接 | 浏览器不使用 ZeroOmega 配置的代理；如果电脑启用了 TUN、其他透明代理或 VPN，系统层仍可能接管连接 |

需要浏览器独立选线时选择**具体节点模式**。系统代理受 Windows 当前设置影响，不能单凭菜单名称保证它正在使用哪一个客户端。

## 以后更新怎么做

- **原版：** Clash 更新或切换订阅 → 探测环境 → 生成备份 → 需要时确认写回 → ZeroOmega 恢复新 BAK。
- **新版：** Clash 更新订阅 → 刷新 → 勾选并应用订阅选择 → 检测节点 → 生成合并 BAK → ZeroOmega 恢复新 BAK。

本软件的刷新读取 Clash 已下载的配置，不代替 Clash 向服务商更新订阅。保留自己的私有状态目录，避免丢失稳定的节点与端口登记；不要把订阅、凭据、完整配置或私有目录分享给别人。

若导入后无法连接，先确认对应核心已运行、最新配置已应用且套餐有权限，再看节点测试结果。ZeroOmega 的失败资源提示可能包含被规则拦截的广告；不要仅凭提示数量判定整条线路不可用，也不要为消除提示添加自动换线规则。
